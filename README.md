# Projeto pessoal

Repositório de uso pessoal para experimentos, automações e pequenas ferramentas de organização e pesquisa.

O conteúdo aqui é mantido para aprendizado e uso próprio. Alguns componentes podem executar tarefas localmente no Windows e outros podem gerar páginas ou dados auxiliares por meio do GitHub Actions.

## Estrutura

- ferramentas locais para Windows;
- rotinas automatizadas;
- páginas auxiliares;
- arquivos de configuração e testes.

Este repositório não representa serviço comercial, não possui vínculo com as empresas ou plataformas consultadas por suas ferramentas e pode mudar a qualquer momento conforme minhas necessidades pessoais.
